# Installing the skill in Claude Desktop

1. Zip the `shape-my-question` folder (the folder, not its contents).
2. Claude Desktop → Settings → Capabilities → Skills → upload the zip.
3. Create a Project "Northstar analytics" and paste `project-instructions.md` into its instructions.
4. Restart Claude Desktop after the MCP config change; pick one of the three `northstar-as-*` servers per conversation to play a role.
